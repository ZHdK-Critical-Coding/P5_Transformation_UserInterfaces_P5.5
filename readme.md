# P5 -> P5.5

Example for p5.5.js by Kris Heyse: work
in real-world units (millimeters) with `mmpx()`, set up with
`p5.initMetrics(displayDiagonalInInches, exportPPI)`. Includes pan/zoom and
export helpers.

## How to Use

1. Start Live Server (click **Go Live** in the VS Code status bar).
2. Adjust the parameters of `p5.initMetrics()` at the top of `sketch.js` to match your display.
3. Use the mouse buttons and mouse wheel to pan and zoom.
